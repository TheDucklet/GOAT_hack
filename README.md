# GOAT_hack

Реализованы членства и административные доступы.

Реализованные операции отмечены в OpenAPI значением implemented.
Ещё не подключённые операции возвращают 501 после проверки доступа.
Правила доступа и схемы находятся в docs/contracts.
Исходный реестр задач команды находится в TASKS.md.
