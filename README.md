# GOAT_hack

Реализована серверная часть новостной аналитики.
Инструкции запуска находятся в backend/README.md.
Схемы обмена находятся в docs/contracts/openapi.json и docs/contracts/integration.md.
Результаты проверок и состояние интеграции находятся в docs/qa и docs/publication.md.
Frontend и общий Docker Compose готовит Роман. AI готовит Фёдор.
Подключение этих частей остаётся отдельной совместной проверкой.
