# Backend

Используется Python 3.12 и PostgreSQL 17.
Зафиксированные зависимости устанавливаются командой pip install с файлом requirements.lock.
Из каталога backend миграции запускаются командой python с аргументами модуля app.cli migrate.
Для просмотра Swagger запускается модуль uvicorn с приложением app.main:app.
Конфигурация задаётся в локальном .env по образцу .env.example.
Тесты запускаются через модуль pytest. Для интеграционных тестов PostgreSQL используется отдельная база goat_test.
Для проверки первой миграции используется отдельная база goat_a01_test.
Подробные команды для схем сохранены в docs/contracts/README.md.
Полная инструкция эксплуатации будет опубликована в задаче документации.
