# Поиск по банковской аналитике

Поиск возвращает фрагменты распознанных PDF с документом, страницей и цитатой. Отдельная векторная или графовая база не используется, поиск строится на полнотекстовом индексе PostgreSQL (`to_tsvector('russian', text)` с GIN-индексом, слой доступа `backend/app/services/tools.py:BankRepository.search_chunks`) и фильтре даты документа.

## Функция search_bank_analytics

`backend/app/ai/rag/search.py:search_bank_analytics(query, as_of, limit, repository)` вызывается инструментом агента `AnalysisTools.search_bank_analytics`. Максимум результатов равен 5, длина запроса ограничена 1000 символами.

Репозиторий выполняет `plainto_tsquery`, то есть требует наличия всех слов запроса, а естественный вопрос редко содержит все слова фрагмента. Поэтому функция работает в четыре шага.

1. Из запроса выделяются содержательные слова (без стоп-слов, с сохранением аббревиатур вроде «ЦБ» и чисел), не больше восьми.
2. Репозиторию отправляются варианты запроса: все слова, все слова без одного, все пары и каждое слово отдельно, не больше 40 вариантов. Повторяющиеся фрагменты объединяются по `chunk_id`.
3. Фрагмент остаётся в выдаче, если в нём найдено не меньше 60% слов запроса (для одного слова – само слово). Слова сравниваются по первым пяти буквам, чтобы форма слова не мешала совпадению.
4. Оставшиеся фрагменты упорядочиваются по весу слов (редкие слова среди кандидатов весят больше, повторы в тексте добавляют логарифмически) и доле найденных слов.

Если подходящих фрагментов нет, возвращается пустой список и причина в `empty_reason`, выдуманный фрагмент не создаётся.

## Результат

Каждый элемент содержит `chunk_id`, `document_id`, `version`, `index_version`, `page` (номер страницы PDF с единицы), `document_date`, `text`, `excerpt`, `locator` (`{"page": N}`), `score` и признаки даты.

- `date_unknown` истинен, если у документа нет даты. Такой фрагмент остаётся в выдаче и помечен явно.
- `historical` истинен, если документ старше даты запроса `as_of` больше чем на 365 дней.
- Документы с датой позже `as_of` исключаются в SQL-запросе и повторно проверяются в коде.

`excerpt` – окно в 320 символов вокруг плотнее всего расположенных слов запроса, оно используется как цитата в Evidence (`kind=bank`, `locator.page`).

## Фрагментация и индекс

Текст каждой страницы режется на фрагменты по 1200 символов с перекрытием 200 (`AI_RAG_CHUNK_CHARS`, `AI_RAG_OVERLAP_CHARS`, см. `docs/ai/ocr.md`). Для каждого фрагмента сохраняются `chunk_id`, документ и версия, страница, дата документа и текст. Версия индекса `index_version` меняется вместе с содержимым фрагментов.

## Команда reindex

Из каталога `backend` при заданном `DATABASE_URL`:

```bash
python -m app.ai.rag reindex --pdf-dir ../data2 --migrate
```

Команда применяет миграции (`--migrate`), регистрирует PDF каталога как документы (если их ещё нет), затем для каждого документа запускает обработчик задания `ingest_document_job` backend. Обработчик вызывает `ingest_bank_document`, проверяет страницы и заменяет фрагменты документа. Распознанные страницы берутся из кеша OCR, поэтому повторный запуск не обращается к модели. Параметр `--document-id` ограничивает работу одним документом.

## Проверка качества

`docs/ai/retrieval-queries.json` содержит пять контрольных запросов с ожидаемыми страницами, определёнными просмотром PDF до запуска проверки.

| Запрос | Ожидаемая страница |
| --- | --- |
| Какое решение принял ЦБ по ключевой ставке в сентябре | `ALFA-Macro_Insights-Policy_Rate_11Sep.pdf`, стр. 1 или `Бонд_Бриф_14092026.pdf`, стр. 1 |
| Как изменилась недельная инфляция в конце августа | `Inflation_tracker_02.pdf`, стр. 1 |
| Что банк говорит о динамике потребления | `ALFA-consumption.pdf`, стр. 1 |
| Почему цена золота выросла в августе | `Gold_digest_August26.pdf`, стр. 2 |
| Прогноз цен на литий и кобальт в Боливии | пустой результат |

Команда проверки выполняет запросы через настоящий `BankRepository` на PostgreSQL и записывает результат в `docs/ai/retrieval-checks.json`:

```bash
python -m app.ai.rag check
```

Для четырёх содержательных запросов ожидаемая страница попадает в первую пятёрку (на первом месте для трёх запросов, на третьем для запроса о потреблении), для темы без подтверждений результат пуст. Тесты логики лежат в `backend/tests/test_ai_rag_search.py`.

## Ограничения

- Поиск лексический, синонимы и перефразировки без общих слов не находятся. Уточнение запроса при пустой выдаче выполняет агент (F-07).
- Слова сравниваются по префиксу из пяти букв, поэтому изредка совпадают разные слова с одинаковым началом.
- Вес считается среди найденных кандидатов, а не по всему корпусу.

## Локальный снимок фрагментов

Команда `python -m app.ai.rag export` из каталога `backend` записывает все проиндексированные фрагменты в `docs/ai/fixtures/bank-chunks.json`. Класс `backend/app/ai/rag/file_repository.py:FileRepository` читает этот файл и повторяет контракт `BankRepository.search_chunks` (все слова запроса, сравнение по первым пяти буквам, фильтр даты), поэтому поиск и агент можно запускать без базы данных. Результаты на PostgreSQL могут незначительно отличаться из-за морфологии `to_tsvector('russian')`.
