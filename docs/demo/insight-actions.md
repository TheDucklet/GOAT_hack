# Действия с анализом — R-09

Откройте «Бизнес-аналитику», выберите компанию и событие. В текущей ленте подготовьте анализ; готовая snapshot-карточка открывается по сохранённому `insight_id`. Подготовка и жизненный цикл snapshot-ленты остаются задачей R-13.

В готовой карточке нажмите «Полезно» или «Не полезно». Подсветка появляется после ответа сервера; оценка доступна при следующем открытии анализа. Повтор выбранной оценки не отправляет запрос. Оценку можно изменить.

«Скрыть» в анализе скрывает эту версию для текущего пользователя и компании. Обновлённый анализ может появиться снова. «Скрыть событие» под новостью скрывает все его версии. В разделе «Скрытые события» можно вернуть конкретную запись, в том числе после перезагрузки. Глобальное скрытие оператором этим действием не отменяется; другие ЛПР сохраняют собственную ленту.

«Обсудить с менеджером» открывает подтверждение с контекстом события и компании. До подтверждения и после сохранения показано: **«Демонстрация — запрос в банк не отправлен»**. Сохраняется только запись демо-действия; отправки в CRM, почту или банк нет. Одинаковое действие по этой карточке получает один ключ после reload и сетевого сбоя. При ошибке можно повторить вручную; автоматической отправки нет.

На телефоне используйте ссылки «События и источники», «Анализ», «Чат» над лентой. Источники открываются внутри карточки, защищённый PDF — в отдельной вкладке. Мобильная и настольная версии используют одно состояние. HTML в ответах показывается текстом.

## Воспроизведение приёмки

Только новый отдельный Compose-проект с пустой БД `goat_r09`; пользовательский стек не подходит. В PowerShell из корня репозитория:

```powershell
$env:AI_ENV_FILE='.env.ai.example'
$env:IMAGE_TAG='r09-check'
docker compose -p goat-r09-acceptance -f compose.yaml -f frontend/tests/compose.r09.yaml up --build -d --wait
python frontend/tests/action_smoke.py --project goat-r09-acceptance --channel msedge
docker compose -p goat-r09-acceptance -f compose.yaml -f frontend/tests/compose.r09.yaml stop
```

Тест создаёт случайный пароль в памяти и синтетические данные в отдельной БД; повторяйте на новом имени проекта. Порт 8090 должен быть свободен. AI-ключ принудительно пустой, новости не собираются, модель синтетическая. HTTP, PostgreSQL, очередь, worker, cookie и CSRF настоящие; тест не проверяет качество внешней LLM. Тома после остановки сохраняются.
