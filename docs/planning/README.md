Единственный редактируемый каталог — [plan.json](plan.json). Закрытая исходная постановка сохраняется в нём; старые PDF/исходники сохранены в рабочем каталоге `output/planning/archive/2026-10-19/`. Статус `done` относится к исходной реализации и историческим проверкам, будущая приёмка релизной версии назначена отдельно.

После правки каталога из корня репозитория:

```powershell
python scripts/render_planning.py --check
python scripts/render_planning.py
```

Проверка использует стандартную библиотеку Python: сверяет ID, обязательные результаты/приёмку, зависимости, сроки, покрытие критериев и сохранность закрытых постановок при доступном локальном архиве. Экспорт PDF использует установленные на хосте Playwright, Edge и PyMuPDF; это инструменты подготовки документов, в runtime приложения они не добавлены. `--no-pdf` генерирует только Markdown/HTML.

Генерируются общий TASKS.md, три персональных Markdown, обоснование и четыре PDF в `../output/planning/`. Каждый PDF проверяется на переполнение, число страниц и извлекаемый текст; отчёты — generation-report.json и verification-report.json. `output/planning/source/tasks.json` — производный экспорт для прежних инструментов; источником остаётся plan.json в репозитории.

Кейс.pdf — первичный источник. Предоставленный анализ нейросети — вторичный: его спорные трактовки явно отмечены в DQ-01–DQ-07/ORG-01. Сроки и пороги качества — внутренние договорённости команды; точное время официальной сдачи проверяется в R-12.
