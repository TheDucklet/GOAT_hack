# Проверка A-01

Дата: 20.10.2026. Python 3.12.14, PostgreSQL 17.

- 37 тестов успешно на SQLite.
- 37 тестов успешно с проверкой миграции на отдельной PostgreSQL `goat_a01_test`.
- Первая миграция применяется к пустой БД; повторный upgrade не меняет схему.
- Alembic check не обнаруживает расхождений модели и PostgreSQL.
- OpenAPI совпадает с текущим декларативным реестром операций.
- Каждая операция имеет запрос, успешный статус, результат и правило доступа.
- Проверены JSON-примеры, произвольная должность и запрет выбора роли при регистрации.
- Ruff check и format --check проходят.

Запуск из backend/:

```powershell
python -m pytest -q -p no:cacheprovider
$env:A01_TEST_DATABASE_URL='postgresql+psycopg://user:password@localhost:5432/goat_a01_test'
python -m pytest -q -p no:cacheprovider
ruff check app tests migrations
ruff format --check app tests migrations
```

SQLite не умеет сравнивать PostgreSQL expression index через Alembic; соответствие
GIN-индекса проверено PostgreSQL-прогоном. Starlette сообщает о будущей замене httpx
на httpx2 в TestClient. Эти предупреждения не являются отказами тестов.

остаётся частью командной приёмки; PR автоматически не объединяется.
