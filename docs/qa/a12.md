# Проверка задачи 12

Подготовлен воспроизводимый запуск backend.

Полный прогон этой ветки содержит 71 успешных проверок SQLite. На PostgreSQL прошли 71 проверок. Проверены линтер, форматирование и согласованность OpenAPI с приложением.

Ветка основана на предыдущей задаче. Изменения проверяются относительно её вершины. Объединять запросы следует в порядке зависимостей.
