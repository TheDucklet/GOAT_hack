Команды выполняются из backend в окружении requirements.lock.

```powershell
python -m pytest -q -p no:cacheprovider
python -m ruff check app tests migrations scripts ../scripts
python ../scripts/check_architecture.py
python -m app.cli export-openapi
$env:PYTHONPATH=(Get-Location).Path
python ../scripts/export_feed_contracts.py --check
```

Для PostgreSQL перед pytest задаются TEST_DATABASE_URL и A01_TEST_DATABASE_URL с отдельными тестовыми базами.
Из frontend выполняются contracts:generate, contracts:check, test и build из package.json.
