# Проверка запуска опубликованного backend

Выполнена 20 октября 2026 года на отдельной пустой базе PostgreSQL 17. Проверялась текущая ветка публикации. Начальная миграция 0001 применена дважды. Проверка выявила отправку ответа до завершения транзакции. Для зависимостей БД установлен scope function. Транзакция завершается до отправки ответа. Регрессионный тест воспроизвёл ошибку до исправления и прошёл после него. Повторный seed сохранил три аккаунта и два членства. Проверены настоящий HTTP сервер, вход, контекст компании, загрузка синтетического PDF и защищённое чтение его файла. После перезапуска API сессия и PDF сохранились. Результаты записаны в publication-clean-start.json.

Из каталога backend после установки зависимостей и настройки DATABASE_URL выполняются команды.

```powershell
..\.venv\Scripts\python.exe -m app.cli migrate
..\.venv\Scripts\python.exe -m app.cli seed-demo
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Пароль задаётся локально через DEMO_PASSWORD до запуска seed. Во втором терминале из каталога backend запускается worker.

```powershell
..\.venv\Scripts\python.exe -m app.worker
```

Для импорта используется команда app.cli import-clients с аргументом directory. Исходная папка должна содержать три CSV организаторов. Результаты прежнего полного импорта и перезапуска PostgreSQL сохранены отдельно с указанием происхождения в backend-report.md.

Dockerfile подготовлен для сборки с контекстом backend. Общий Compose и frontend ещё не предоставлены. Образ Docker не собирался. Проверка сохранения данных общей контейнерной сборки и реальных AI результатов остаётся совместной приёмкой. Задача общего развёртывания полностью не закрыта.
