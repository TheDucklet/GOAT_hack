# F-13 — контракт бизнес-влияния v2

Дата: 22.10.2026. Ветка: `f-13/fedor/impact-contract`, основана на локальном
коммите плана `6f8de2f` поверх `origin/main 88f784e`.
Реализация и проверки завершены в ветке; совместное согласование коллегами и
слияние в main этим отчётом не объявляются состоявшимися.

## Результат

- [Контракт и mapping AI → API → UI](../contracts/insight-v2.md), JSON Schema
  v1/v2 и AI-envelope, семь общих синтетических fixtures.
- Единая wire-модель Python; OpenAPI и TypeScript генерируются из неё. Старые
  `examples.json` и `ai-examples.json` не менялись; tagless v1 читается без миграции.
- V2 валидирует ссылки всех новых полей, типы утверждений, наличие механизма и
  обоснования известной силы, неизвестную силу, даты, происхождение сценарных
  входов, диапазоны, банковскую атрибуцию и allowlist действий.
- Worker сохраняет поля v2, сверяет полный каталог ссылок и отклоняет неполный
  каталог до сохранения результата. Существующие проверки доступа к evidence
  и версиям исходных записей остаются частью исполнения.
- `notice_v1` задаёт приложение. Общая политика экспортируется в frontend;
  обязательное уведомление показано на странице аналитики для всех версий.
  Отсутствие disclaimer у модели заполняется приложением, подмена отклоняется.
- Общий namespace contract/schema/semantics/policy включён в оба кеша. Промпты
  уже версионируют AI cache; backend требует смены AI_GENERATION_VERSION при
  изменении промптов/моделей, как описано в контракте.
