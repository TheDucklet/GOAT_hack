## Повторение

Команды статических и unit-проверок приведены в [архитектуре](../architecture.md). Сквозная проверка после запуска и seed:

```powershell
python frontend/tests/membership_smoke.py --channel msedge --output artifacts/r00-browser
python scripts/verify_compose.py --project goat-r02-check --report artifacts/r00-compose.json
```

Вторая команда пересоздаёт только явно указанный проект и сохраняет его тома. Backend-тесты используют отдельные goat_test/goat_a01_test, а не рабочую БД; при запуске из backend-образа docs/contracts подключается read-only. Реальные AI-ключи для проверок не нужны. Реализация новых R-04–R-12 и реального AI остаётся соответствующим владельцам по планам; это архитектурная подготовка текущей сборки.
