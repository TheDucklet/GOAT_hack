## Повторение

```powershell
python scripts/verify_compose_config.py
docker compose -p goat-r02-check up --build -d --wait
python scripts/verify_compose.py --project goat-r02-check --base-url http://127.0.0.1:8080
```

Второй скрипт проверяет реальный HTTP, миграции/повторный seed, запись PostgreSQL, HttpOnly-сессию и shared document volume; пересоздаёт только явно указанный проект без удаления томов и проверяет восстановление данных. Все аккаунты и файлы синтетические, значения паролей/cookie/CSRF не записываются в отчёт. Команды Docker запускаются argv-массивами без shell.

Формальное закрытие требует ревью команды, PR и включения в общую ветку по TASKS.md.
