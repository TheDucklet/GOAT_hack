# R-05 — персональная карточка и основания

Дата: 22.10.2026, МСК. Ветка: `r-05/roman/grounded-impact-cards`, исходный main: `ea23a2c`. Требования: R-05 в [актуальном плане Романа](../planning/roman.md). Зависимости F-13/F-14 и API A-15–A-18 находятся в main.

## Результат

Панель подключена к настоящим buildInsight/insight/jobs без второго транспорта. Генерация запускается явным действием пользователя; повторный render не отправляет POST. Ответ 200 показывается сразу, 202 использует общий polling раз в 2 секунды. После принятого задания сетевой повтор продолжает GET; failed/budget_exhausted требуют ручного действия. Ожидание ограничено 120 секундами на попытку. Смена company/event отменяет запросы, таймеры и публикацию позднего ответа. Ответ сверяется с выбранной компанией и событием. В AnalyticsSelection добавлен insightId, готовая карточка может быть открыта по ID без POST для R-13.

Карточки v1/v2 разделяют facts/bank_view/ai_interpretation/risks/opportunities/actions/unknowns. V2 показывает персональный вывод, механизм, impact_level/impact_reason, горизонт, предпосылки, сроки актуальности и review/expiry. Undetermined подписан «Недостаточно данных». Факты, гипотезы и сценарии имеют разные подписи; старый вывод v1 без типа не объявляется фактом. Формулы, числа с единицами/периодами и диапазоны сценария отображаются текстом без исполнения.

Банковский материал имеет статус и дату. Historical и undated не подаются как сегодняшняя позиция банка; отсутствие позиции допускает внешний анализ. Единый EvidenceLink загружает основание по авторизованному ID: точный news URL, поле/значение/quality профиля либо защищённый PDF с датой и страницей. Ссылка PDF строится из API base, проверенного ID и положительного целого page, не из произвольного URL модели. React экранирует HTML; ссылки news допускают только HTTP(S) без credentials. Доступ повторно проверяет backend.

Общий InsightNotice использует политику приложения notice_v1 и виден внутри панели до загрузки, при ошибке, неполном ответе и в v1. Модель не выбирает и не скрывает текст предупреждения.

## Воспроизводимость и границы

Команды приведены в [frontend README](../../frontend/README.md#карточка-r-05); точные запросы и состояния — в [ui-requests.md](../contracts/ui-requests.md#карточка-и-основания-r-05). Скрипты `frontend/tests/insight_smoke.py` и `insight_fixture.py` отказываются работать с пользовательской БД: seed допустим только в пустой goat_r05. Ранее существовавшие пользователи, документы и данные проекта не менялись. Приёмочные тома сохраняются после остановки.

Браузерный прогон не перехватывает HTTP и использует настоящий backend/очередь/worker. Сохранённые v1/v2 и банковский PDF синтетические; новый job использует явно указанный тестовый producer `tests.fake_feed_ai`. Платных вызовов — 0; ключ AI в этом локальном окружении отсутствует. Это доказательство клиентской интеграции, доступа и отображения, а не отдельная приёмка качества реального LLM. Живая серверная цепочка с моделью ранее подтверждена A-17; общий живой пользовательский сценарий с разрешённым шлюзом относится к R-10. В производственном режиме автоматической подмены модели тестовым ответом нет.
