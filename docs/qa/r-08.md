# R-08 — операторские материалы и задания

23.10.2026, МСК. Ветка: `r-08/roman/material-operations`; исходный main: `728599a8f68c0ce4424d802373c89bbb958d0f9d`. Ветка включает локальную R-07 `3076327`: используются её навигация и общие операторские механизмы. Публикация/CI/слияние обоих коммитов фиксируются в GitHub.

## Результат

В `/admin/documents` реализованы безопасный multipart upload, filename/date/page_count/status/error, явный reindex и основание распознанной страницы. В `/admin/news` показаны источник/дата/глобальная visible/processing_status, подтверждаемое скрытие/возврат, сбор и повтор обработки. `/admin/jobs` показывает операцию, материал, состояние/попытки/ошибку, readonly-мониторинг и повторы поддерживаемых операций. Неизвестная дата обозначена явно, global visibility отделена от персонального скрытия R-09.

Используются один HttpClient/CSRF, общий waitForJob и EvidenceLink, общие admin/shared для R-07/R-08. В PostgreSQL общая очередь возвращает один активный job при одновременной постановке с одним dedup_key; rollback сохраняет границы транзакции. В SQLite оставлен последовательный путь для корректной legacy SAVEPOINT-семантики. Ingest сохраняет проверенное evidence распознанной первой страницы и возвращает source_id; готовый SHA не порождает новый job. AdminJobOut добавляет kind/target_id без полного payload. OpenAPI/generated types обновлены. Новых миграций и runtime-зависимостей нет.

## Реальный OCR

Пользователь явно разрешил отправить три страницы предоставленного `data2/Inflation_tracker_02.pdf` через настроенный `https://changellenge.up.railway.app/v1`, модель `qwen/qwen3-vl-30b-a3b-instruct`. Лимит изолированного тестового стека — **5 ₽**. Файл SHA-256 `09d5537f6a52f5f8f2d9518ed9171e794382972ce38cbdc4bd3099b2db129d0c` действительно загружен через форму и обработан существующим worker/app.ai.bridge.

Результат: **3 страницы, 8 chunks**, дата **2026-09-02**, содержательное evidence страницы 1, защищённый оригинал с тем же SHA и отказ anonymous 401. По сохранённым OCR-результатам: **28 077 входных / 2 663 выходных токена**, **0,6127 ₽**. Это новый реальный OCR, а не импорт старого текста или синтетический producer. Ключ перенесён из заполненного шаблона в игнорируемый `.env.ai`; поле ключа в `.env.ai.example` очищено. Секреты в отчёт и новые артефакты не включены.
