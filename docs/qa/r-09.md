# R-09 — действия с анализом и личная обратная связь

23.10.2026, МСК. Ветка `r-09/roman/insight-actions`, исходный main `ba6845ec429b2579331284c227b994863e2f4996`. Публикация и слияние фиксируются в GitHub после успешного CI.

## Результат

Готовая карточка содержит «Полезно/Не полезно», личное скрытие версии и подтверждаемое «Обсудить с менеджером». Оценка читается с сервера при повторном открытии. Одинаковая оценка не отправляется повторно; backend обновляет одну запись. Демо-действие использует стабильный ключ по user/company/event/insight/action и проверяет контекст ответа. До подтверждения, в диалоге и после сохранения указано: «Демонстрация — запрос в банк не отправлен». Внешних действий нет.

Список личных скрытий читает все страницы с сервера; «Вернуть» работает после reload, включая точную версию анализа. Скрытие события без анализа действует на все версии; скрытие в карточке — на её версию. Сервер определяет пользователя по сессии, проверяет компанию и принадлежность insight, сериализует операции через membership. Глобальная видимость не меняется. Названия глобально скрытых событий в личной истории не раскрываются. Старый DTO из трёх полей сохранён без opt-in `include_details`.

Используются общий HttpClient/CSRF, generated OpenAPI types, ConfirmDialog, ErrorNotice и существующие insight/chat/evidence. Новых runtime-зависимостей и миграций нет. Модуль `analytics/interactions` выделяет API, личные скрытия, действия и телеметрию. В запросы не включаются профиль, свободное сообщение менеджеру или текст чата. Смена контекста отменяет запросы; успех показывается только после подходящего ответа сервера. Повторы действий явные.

Open записывается при открытии проверенного сохранённого анализа; impression — когда область действий видна на 50% непрерывно одну секунду в активной вкладке. Новости без insight не дают эти события. Сервер выполняет дедупликацию, headless/admin/test исключены из продуктовых метрик. При отсутствии IntersectionObserver или ошибке телеметрии показ не выдумывается. Обратная связь, скрытие/восстановление, действие и чат учитываются серверными обработчиками A-16.
