# Метки модели (не ручная разметка)

Файлы `calibration-labels-codex.csv`, `control-labels-codex.csv` и `validation-report-codex.md` получены 25.10.2026 от Романа, но, как сказано в `validation-report-codex.md`, оценки выполнены моделью (Codex) по запросу пользователя. Авторство человека и статус независимой ручной разметки там не заявляются.

Как это учитывается:

- Метки модели не заменяют ручную калибровку. Требование дополнения к F-16 (два участника, не автор генератора, независимо оценивают источники и утверждения, ещё одна LLM процедуру не подменяет) не выполнено, калибровка судьи остаётся INCOMPLETE.
- Файлы названы `-codex`, а не `-roman`, и лежат отдельно от каталога меток людей, чтобы их не принять за ручные при расчёте согласованности.
- Метки калибровочного листа допустимо использовать только как разведочный сигнал при разработке (например, увидеть, где судья расходится с другой моделью). Метки контрольного листа для настройки не используются: контрольная выборка должна остаться не использованной при настройке судьи.
- В отчёте о качестве метки модели указываются как «оценка модели», а не как человеческая разметка.
