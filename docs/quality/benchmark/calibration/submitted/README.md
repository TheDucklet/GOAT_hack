Метки модели до этого появились в рабочем процессе Романа, поэтому его разметка не слепая относительно них;

Как это учитывается:

- Это разметка одного человека, не слепая относительно меток модели. Требование двух независимых участников не выполнено, калибровка судьи остаётся INCOMPLETE и снимается только после второй независимой ручной разметки.

- В отчёте метки указываются как «вердикты Романа, комментарии оформлены моделью, одна разметка».
