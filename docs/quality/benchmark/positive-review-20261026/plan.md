# Приёмка исправлений F-16: шесть положительных случаев

План зафиксирован 26.10.2026 до новых вызовов моделей. Проверяется рабочий AI-код main `9bc77e99d1da8d47c462763a84c9da6403e59532` (PR #49), а не новая правка генератора.

Роман явно разрешил в рабочей сессии новый живой прогон шести случаев с **общим пределом 15 ₽**. Один новый журнал включает суммаризацию, проверку фактов, агент/генерацию, допуск к публикации и автоматического судью. Предел не сбрасывается при смене бюджетных суток. Повторная генерация после отказа качества не выполняется; в рабочем gate остаётся одна попытка исправления удалением. Разрешено не более одного транспортного повтора на вызов.

Входы фиксируются командой `run_review.py --prepare` в `inputs.json` до первого вызова. Шесть pair_id без изменений взяты из `targets-ranking-v2.json`. Компании синтетические; пользовательские фокусы заморожены из run-3. Три исходных события: пересказ публичной новости Банка России о ставке и явно синтетические новости о жилье и IT-льготах. Материалы банка — ранее распознанный `docs/ai/fixtures/bank-chunks.json`. Новые PDF, изображения, исходные клиентские CSV и шесть отложенных событий не используются.

Суммаризация трёх событий выполняется заново рабочей summary-3. Далее каждый случай один раз проходит текущие `build_published_insight`, строгую схему/provenance и backend `require_publication`. Автоматическая диагностика содержательности: механизм с основаниями news и company, итог allow; у B06 impact_level=undetermined. Содержание дополнительно читается по шести согласованным ожиданиям из decision record. Нет требования искусственно получить определённый impact у остальных компаний.

Опубликованные по gate результаты оцениваются фиксированным judge-3 с идентичностью. Это автоматический оценщик, его независимая человеческая калибровка ещё INCOMPLETE. Метрики/отказы не объявляются окончательной приёмкой F-16. Этот ограниченный прогон с локальными инструментами по замороженному корпусу не подменяет 84/42 benchmark, ручную разметку, PostgreSQL/VPS, UI/worker и финальную R-10/R-11.

Локальные технические исправления проверяются уже выполненными для того же main тестами: 771 passed / 6 skipped, пять независимых контролей PASS, CI frontend/backend/compose PASS. Новые исходники приложения, модели, промпты, пороги и метки в рамках этого review не меняются.
