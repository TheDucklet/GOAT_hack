## Что не меняется после запуска

Пороги, метки, правила ранжирования, судья, промпты и допуск к публикации между run-3 и run-4 не меняются. Если после run-3 потребуются исправления генератора, run-4 остаётся не запущенным до явного решения, а отложенный набор после использования для правок становится регрессионным.

## Ограничения плана

- Калибровка судьи остаётся INCOMPLETE: человеческая разметка одного участника, второй независимой разметки нет.
- Пороги ranking на исходном наборе информационные, он уже использовался для правок.
- Живой сценарий API → worker → AI требует доступа контейнеров к шлюзу и в этот запуск не входит.
