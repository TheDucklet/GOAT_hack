# run-2: недействительный запуск (дефект проверки фактов события)

Запуск 25.10.2026 на SHA `bad1a48` исходных 84 пар. Результат не используется ни как «после», ни как доказательство качества и сохранён как отрицательный итог без правок.

Что произошло: промпт проверки фактов события (`factcheck-1`) не требовал разбор на части, а общий проверяющий принимает вердикт только при наличии разбора, поэтому все факты и предложения краткого содержания получили статус «не проверено» и были отброшены. События остались без фактов, а карточки строились из запасного пути, который брал первое предложение публикации как «факт». Итог: 49 готовых и 35 отказов проверки (28 `repair_failed`, 7 `repair_invalid`), расход 60,0 руб., временных ошибок шлюза не было.

Причина не поймана тестами: тестовый проверяющий всегда возвращал разбор на части, а живой замер проверяющего на метках выполнялся только для проверки допуска карточки, не для проверки фактов события. Исправления (коммит после `bad1a48`): промпт `factcheck-2` возвращает разбор на части, запасной путь с первым предложением отключён для событий, прошедших суммаризацию, добавлены тесты и живой дымовой прогон суммаризации на трёх событиях до платного запуска.

Повторный замер исходных 84 пар идёт под идентификатором `run-3`, новый набор из 42 пар под `run-4`.
