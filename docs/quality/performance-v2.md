Измерения A18 от 22 октября 2026 года.

Полный импорт и независимая сверка проведены на Windows 11 с процессором AMD64 Family 25 Model 116 и 12 логическими процессорами. Использованы Python 3.12.14 и PostgreSQL 17 в локальном Docker. Полные результаты и хеши входных файлов находятся в data-coverage-v2.json. PostgreSQL использовал отдельную базу goat_a18. Исходные пользовательские окружения не пересоздавались.

Импорт 85 525 строк компаний, 12 514 строк связей физических лиц и 1 380 585 платёжных строк занял 114.52 секунды. Полная построчная проверка заняла ещё 17.61 секунды. Пик рабочего набора процесса импорта и проверки составил 958 341 120 байт, около 914 МиБ. Измерение получено через GetProcessMemoryInfo. Это память процесса Python, без памяти PostgreSQL и Docker. До этого измерения выполнен отдельный прогон сверки. Поэтому файловый кеш операционной системы мог быть прогрет. Результат не заявляется как холодное чтение диска.

Повторный импорт не размножает записи. Все исходные строки компаний и физических связей сохранены с происхождением. Каждая платёжная строка сопоставлена с исходной строкой, суммой, количеством и сторонами. Суммы и количества проверены отдельно. Сумма категорий external, self и quarantined равна общему итогу. Категория карантина учитывается отдельно и не подменяется внешним оборотом. Неизвестные единицы и периоды не объявляются известными. Наблюдаемые групповые связи не объявляются консолидированной выручкой.

Измерение ленты использовало эту же базу с полными платёжными данными, один реальный профиль Client и 3000 синтетических событий. HTTP выполнялся через FastAPI TestClient внутри процесса. Это не измерение браузера, сети или публичного сервера. Рабочее окно ранжирования составило 2000 событий, shortlist 30, top K 3. Для подготовки использован явно синтетический AI модуль. Он позволяет измерить накладные расходы backend без модели и не подтверждает скорость настоящего LLM.

На 30 последовательных запросах v1 медиана составила 146.123 мс, p95 составил 158.210 мс. На 30 запросах повторного чтения v2 медиана составила 213.544 мс, p95 составил 250.957 мс. При четырёх параллельных запросах v2 на 40 измерениях медиана составила 811.087 мс, p95 составил 881.243 мс. P95 выбран как ближайший верхний порядковый элемент для 95 процентов измерений. Холодное создание снимка заняло 276.776 мс. Подготовка трёх карточек синтетическим модулем заняла 298.139 мс. Повторное чтение не вызывало AI.

Живые задержки модели и расходы фиксируются отдельно в docs/qa/a17-live.json. Значения синтетического benchmark не используются вместо живых измерений. Команды запуска приведены в backend README.

Ранжирование выполняется в памяти по ограниченному окну последних 2000 событий. Дополнительно рассматриваются действующие карточки из последних 200 собственных результатов. Это явные пределы текущей реализации. Широкое покрытие истории потребует отбора кандидатов в БД, индексов и отдельной политики сохранения активных влияний. Показатель p95 при четырёх запросах не подтверждает работу с произвольным количеством пользователей.

AI кеш и бюджет используют файловые блокировки одного хоста и общий постоянный том API и worker. Решение предназначено для одной машины. Для нескольких независимых хостов потребуются транзакционные резервы в PostgreSQL либо другое общее хранилище с распределённой синхронизацией. Лимит шлюза остаётся окончательным общим ограничением командного ключа. Локальный ledger не видит вызовов коллег вне этой сборки.

NEWS_SOURCES_CONFIG задаёт путь к JSON конфигурации дополнительных RSS источников. Пример config/news-sources.example.json подключает третий канал Банка России с новостями и выступлениями. Это дополнительный канал того же издателя, а не третий независимый издатель. Список каналов подтверждён официальной страницей https://cbr.ru/development/RSS/. Условия использования опубликованы на https://cbr.ru/about/ и требуют ссылки на первоисточник. Прямой URL сохраняется у каждой публикации. Доступность этого дополнительного канала в живом окружении не подменяется синтетическим тестом.

Отказ основных источников и работа настроенного резерва проверены через управляемый HTTP transport. Добавление отрасли 62.01 проверено через данные профиля и topics без изменения ranker. Код универсального импортера и провайдера не копируется. Интерфакс остаётся отдельным исходным источником. Наличие RSS само по себе не предоставляет права перепубликовывать его материалы полностью.
