1. Завершить полный F-16: независимая калибровка, held-out метки и единый свежий прогон; опубликованный общий GCR **43/54 < 90%**. Исправленный целевой чат 16/16 + smoke 8/8 не закрывает этот gate.
2. Подтвердить R-11 на окончательном SHA: 14/14 и повтор **другим участником**. Автоматический чистый запуск доказывает воспроизводимость инфраструктуры, не заменяет человеческую подпись.
3. Оператор VPS должен сверить развёрнутый SHA с manifest, подготовить реальные банковские материалы, отдельные demo-доступы и проверить HTTPS/secure-cookie/HTTP redirect. Изменений VPS в R-12 не выполнялось.
4. Роман сообщил дедлайн **26.10.2026 17:50 МСК** и формат: **PDF со ссылкой на GitHub**, отправку он выполняет сам. Первичное сообщение организаторов и требование непрерывного хостинга пока не приложены. Требование внутреннего плана «заморозить за 3 часа» уже не выполнено к началу этой работы.

Известные эксплуатационные ограничения: длительная worker-транзакция может задержать повторный вход того же пользователя; после аварийного выключения failed/running job может потребовать явного повтора; наличие PDF не гарантирует подходящую текущую позицию банка. Они перечислены в README и не скрываются от проверяющего.

## Фиксация и отправка

После коммита и CI выполните `python scripts/release_manifest.py` из корня. Manifest создаётся **снаружи коммита** в игнорируемом `artifacts/release`, чтобы не возникало невозможной ссылки коммита на собственный SHA. ZIP содержит только отслеживаемые Git-файлы этой версии. Для тега используйте `--tag`, тег обязан разрешаться в HEAD.

Скрипт также формирует `submission.html` со ссылками и точным SHA. Его можно сохранить в PDF через печать браузера. Роман самостоятельно отправляет этот PDF организаторам; автоматической отправки нет. Ссылки включают repository URL, конкретную версию, service URL, README и runbook. ZIP/manifest и презентация предоставляются дополнительно. Факт отправки заявки/доступов не подтверждён. Не берите версию из этого текста: окончательный SHA задаёт manifest.

Оператор независимого повтора заполняет [D01–D14](../demo/runbook.md), фиксирует фактический расход и подписывает результат. Для каждого непроверенного пункта сохраняется N/A. Разрешение на публикацию кода не считается подписью под качеством модели.
