01 / Пользовательская задача

«Что это значит для нашей компании?»

Финансовый директор

Проверяет ликвидность, стоимость денег и условия финансирования.

Главный бухгалтер

Проверяет факты, договорные условия и последствия для учёта.

Один источник → разные подтверждённые признаки компании → условный механизм → понятный следующий шаг.

Наличие кредитного продукта не раскрывает ставку и сумму договора. Недостающие данные остаются неизвестными.

«Обсудить с менеджером» — подтверждаемая запись внутри прототипа. Заявка в банк не отправляется. См. CJM.

Компании вымышлены. Новости — датированные пересказы Банка России. Новизна demo не является held-out оценкой качества.

06 / Воспроизводимость

Четыре сервиса, один Compose

React / TypeScript → nginx → FastAPI
PostgreSQL + отдельный worker
Общие PDF/OCR-кеш и денежный ledger

Digest образов и lock-файлы
Cookie/CSRF и права компании
Сохранение истории в постоянных томах

docker compose up --build -d --wait
docker compose exec -T api python -m app.cli seed-showcase

Для AI нужен серверный ключ; для позиции банка — подготовленный корпус. Без ключа инфраструктура работает, генерации не подменяются.
